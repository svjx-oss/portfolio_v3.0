**UX changes:**

- Projects: simple list with dividers (not card grid) — title, description, tags, optional link
- Blog index: simple date + title list (leerob style) — no cards, no excerpts, no author badges
- Blog post: TOC shows H1 + H2, collapses via `<details>` (no JS)
- Footer: text links only (no icons)
- Nav: one dropdown for all breakpoints (localized, right-aligned)
- Dark-only (no light mode toggle)

### Backend simplification

| Removed | Why |
|---|---|
| zod | Hand-rolled validation is ~50 lines for our simple schemas. No dependency. |
| sanitize-html | markdown-it's built-in HTML safety + a 10-line allowlist function. |
| markdown-it-anchor | Heading IDs generated by a 10-line slugify function. |
| `authors.json` | Single author — hardcoded in component. Drops a file + schema + cross-file check. |
| `analytics.ts` lib | Analytics is an inline `<script>` in Seo + ~40 lines of event delegation. No module. |
| `{resume}` token | Direct path in markdown. No token substitution complexity. |
| `BlogCard.tsx`, `AuthorBadge.tsx`, `ProjectCard.tsx`, `SkillCard.tsx`, `Toc.tsx` | Inline in their parent pages — 3-5 lines each. Fewer files. |
| `paths.ts` | One-liner, inline in loaders. |
| Tag color map in JSON | Fixed CSS classes instead. No inline styles, no luminance helper. |
| `file`/`url` split on projects | One `link` field. |

**Total dependencies: 5** (fresh, preact, @preact/signals, @fresh/plugin-vite, markdown-it). Down from 9.
