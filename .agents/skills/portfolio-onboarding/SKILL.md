# Portfolio Onboarding

Load this skill before making changes in this project.

## Read First

| Change type | Read |
| --- | --- |
| Any change | `detailed_design/README.md` |
| Active work and verification | [Personal Portfolio Linear project](https://linear.app/svjx/project/personal-portfolio-6202ca3cda15) and `detailed_design/implementation_plan/implementation_plan.md` |
| Shared layout, styles, or accessibility | `detailed_design/high_level_designs/01_theme_and_design_system.md`, `03_layout_and_navigation.md`, and `09_wireframes.md` |
| Routes, components, or content loading | `detailed_design/high_level_designs/00_high_level_architecture.md` and `02_content_data_model.md` |
| Page-specific work | The matching document in `detailed_design/pages/` |
| Testing, deployment, analytics, or content authoring | The matching document in `detailed_design/addons/` |

## Required Skills

| Task | Load skill |
| --- | --- |
| Any jj or VCS command | `jujutsu` |
| Create or edit a jj change description | `commit-message` |
| Deno, Fresh, or frontend work | `deno` and, when relevant, `deno-frontend` |
| Deno deployment | `deno-deploy` |

## Linear Project Assignment

Before creating or updating a Linear issue, read `detailed_design/README.md` and resolve the Linear project linked in its `Any change` row. Assign the issue to that project unless the user explicitly directs otherwise. Do not infer a project from the team, issue title, or current workspace state.
